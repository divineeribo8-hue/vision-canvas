# Vision Canvas

Create a complete, premium website for DIVINE AESTHETICS MEDIA AGENCY, a Nigerian photography, videography and visual storytelling brand.

The website should function as a digital creative studio, portfolio, service catalogue and client booking experience.

It should feel like an intentional creative brand—not a generic photography template and not an overly corporate booking website.

BRAND IDENTITY

Brand Name:
Divine Aesthetics Media Agency

Brand Positioning:
A visual storytelling and creative media agency that translates people's visions, identities, feelings and stories into intentional visual representations.

Core Idea:
FROM VISION TO VISUAL.

Brand Statement:
YOUR VISION DESERVES TO BE SEEN.

Brand Philosophy:
Authenticity, creativity, imagination, intentionality, empathy and meaningful visual communication.

The brand should communicate beauty in a way that is pure, honest and true, while allowing every person's individual aesthetic and identity to be expressed without being boxed into one definition of beauty.

Divine Aesthetics should feel like a creative studio and visual storytelling agency, not simply a photography business.

COLOUR PALETTE

Use a restrained, sophisticated palette:

Warm Ivory — primary background
Soft Cream — secondary background
Charcoal — primary text and strong contrast
Earthy Brown — subtle accents and visual warmth

Keep the colours muted, warm and timeless.

Avoid:

Bright colours

Neon

Excessive gold

Heavy black backgrounds

Overly feminine pink/purple palettes

Loud gradients

The overall appearance should feel warm, editorial, artistic and sophisticated.

VISUAL STYLE

Use:

Large cinematic photography

Editorial magazine-inspired layouts

Generous whitespace

Elegant typography

Strong image-to-text balance

Asymmetrical layouts where appropriate

Clean grids

Subtle borders and dividers

Sophisticated spacing

Minimal but intentional animations

Full-width imagery where appropriate

High-quality visual storytelling

Photography should be the dominant visual element.

Do NOT make the website look like:

A generic Canva photography template

A wedding photography website

A corporate agency website

A social-media influencer website

An overly luxurious/fake luxury brand

A cluttered booking platform

The website should feel artistic, intelligent, intentional, authentic and timeless.

TYPOGRAPHY

Use an elegant editorial serif font for major headlines and a clean modern sans-serif font for body text, navigation and buttons.

Create strong typographic hierarchy.

Headlines should feel sophisticated and artistic.

Body text should remain highly readable.

Buttons should be clean, minimal and easy to understand.

WEBSITE NAVIGATION

Keep the main navigation simple:

HOME
THE WORK
SESSIONS
ABOUT
CONTACT

Include a prominent button:

BOOK A SESSION

The navigation should remain visible and easy to use throughout the website.

IMPORTANT BOOKING LOGIC

The website must distinguish between:

BOOKING REQUEST SUBMITTED

and

BOOKING CONFIRMED

A client submitting the request does NOT automatically mean Divine Aesthetics has confirmed the booking.

The final confirmation happens after Divine Aesthetics reviews the request.
