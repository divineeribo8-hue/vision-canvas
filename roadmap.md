# Roadmap

- Build the complete Divine Aesthetics website with the existing requested architecture and booking journey.
- Add an editable portfolio structure with placeholder slots for owner-uploaded images and videos.
- Add a Selected Work gallery on the home page with 6–9 replaceable placeholders.
- Keep the full multi-step booking flow: service, package, pricing, date/time, details, location, inspiration upload, vision, review, contact method, and request-received status.
- Keep a calendar-ready availability layer that can later connect to Google Calendar and exclude unavailable periods.
- Make inspiration upload behavior honest: distinguish locally selected files from successfully stored/transmitted files.
- Generate WhatsApp and email messages automatically from the client’s booking details.
- Clearly distinguish booking request sent from booking confirmed.
